Setup guide — click to expand

Step 1 — Create a Supabase project
Go to supabase.com, sign up free, and create a new project. Wait for it to provision (~1 min).

Step 2 — Run this SQL to create your tables
In your Supabase dashboard → SQL Editor → New query, paste and run:

create extension if not exists "uuid-ossp";

create table items (
  id uuid primary key default uuid_generate_v4(),
  name text not null,
  category text,
  location text,
  qty int default 1,
  sku text,
  notes text,
  created_at timestamptz default now()
);

create table checkouts (
  id uuid primary key default uuid_generate_v4(),
  item_id uuid references items(id),
  item_name text,
  qty int default 1,
  person text,
  due_back date,
  note text,
  status text default 'out',
  created_at timestamptz default now()
);

create table reservations (
  id uuid primary key default uuid_generate_v4(),
  item_id uuid references items(id),
  item_name text,
  qty int default 1,
  person text,
  start_date date,
  end_date date,
  note text,
  status text default 'active',
  created_at timestamptz default now()
);

create table activity_log (
  id uuid primary key default uuid_generate_v4(),
  type text,
  item_id uuid,
  item_name text,
  qty int,
  person text,
  note text,
  created_at timestamptz default now()
);

-- Allow public read/write (the app uses PINs for access control)
alter table items        enable row level security;
alter table checkouts    enable row level security;
alter table reservations enable row level security;
alter table activity_log enable row level security;

create policy "public all" on items        for all using (true) with check (true);
create policy "public all" on checkouts    for all using (true) with check (true);
create policy "public all" on reservations for all using (true) with check (true);
create policy "public all" on activity_log for all using (true) with check (true);

Step 3 — Add your credentials to index.html
In Supabase: Project Settings → API. Copy Project URL and anon public key. Paste them at the top of index.html replacing YOUR_SUPABASE_URL and YOUR_SUPABASE_ANON_KEY. Also change the PINs.

Step 4 — Publish to GitHub Pages
1. Create a free account at github.com
2. New repository → name it storage-closet → public
3. Upload your index.html file
4. Settings → Pages → Source: main branch → Save
5. Your URL will be https://yourusername.github.io/storage-closet

Default PINs (change these!)
User PIN: 0000 — can browse, check out, reserve, return
Admin PIN: 1234 — can also add/remove items and adjust quantities
